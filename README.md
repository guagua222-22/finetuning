# Agent 微调学习实践

从训练数据、评测到模型微调的循序渐进学习项目。每个实验说明操作内容、目的与运行结果。

## 当前进度：第一课——训练样本与动作检查

通过计算、缺少城市的天气查询、概念问答三个案例，学习：

- 将用户请求标注为正确动作：调用工具、追问或直接回答。
- 区分 JSON 结构合法与动作符合用户需求。
- 将规则、请求和正确输出组织为 SFT 消息样本。

当前使用人工标注与固定错误示范，尚未调用模型或运行训练。三条样本用于理解格式，不能据此评估微调效果。

## 运行

需要 Python 3.9 或更高版本，只使用标准库。

```bash
git clone https://github.com/guagua222-22/finetuning.git
cd finetuning
python -X utf8 lesson01.py
```

脚本会展示正确标签与错误动作检查，并在脚本所在目录生成教学样本和检查报告。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `lesson01.py` | 第一课代码，逐步输出实验过程 |
| `lesson01.samples.jsonl` | 三条 SFT 教学样本，每行一条记录 |
| `lesson01.report.json` | 固定错误示范的结构和动作检查报告 |
| `lesson01.visual.html` | 对话交互演示的 HTML 片段源文件，依赖宿主样式与运行环境 |

## 理解检查结果

三个固定错误动作都能通过结构检查，但都未通过动作检查。这说明仅检查 JSON 格式不足以判断 Agent 是否正确完成任务。

`action_matches` 只检查动作类别、工具名称和参数；直接回答与追问的文本质量仍需额外评测。此实现是教学用的最小示例。
